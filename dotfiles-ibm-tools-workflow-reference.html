fzf Keyboard Shortcuts

ShortcutWhat happens
Ctrl+TFuzzy search files in the current directory — pastes selected path onto the command line. Preview pane shows file via bat.
Ctrl+RFuzzy search command history — select any previous command to rerun it.
Alt+CFuzzy search directories and cd into the selected one.
↑ / ↓Inside fzf: navigate results. In the prompt: history search filtered to commands starting with what you've typed.
Ctrl+F / tatmux-sessionizer — fzf over project dirs, create or switch named tmux sessions.

Neovim — Key Plugins

telescope.nvim
Fuzzy finder inside Neovim
  • Find files, grep across project, search buffers
  • Browse git commits, LSP symbols, diagnostics
oil.nvim
File explorer as a buffer
  • Edit the filesystem like a text file
  • Rename, move, delete files with normal vim motions
harpoon
File bookmarking
  • Pin up to 4 files, jump between them instantly
  • Eliminates buffer hunting in large projects
blink.cmp
Autocompletion
  • LSP completions, snippets, path completion
  • Shows type signatures and docs inline
LSP (built-in)
Language Server Protocol
  • Go-to definition, find references, hover docs
  • Inline diagnostics (errors, warnings)
conform.nvim
Auto-formatting
  • Format on save via Prettier, Black, stylua etc.
  • Runs the right formatter per filetype automatically
gitsigns.nvim
Inline git feedback
  • Shows added/changed/deleted lines in the gutter
  • Stage hunks, preview diffs without leaving the file
DAP (debugger)
Python + JS/Node
  • Breakpoints, step-through, watch variables
  • debugpy for Python, js-debug-adapter for Node
nvim-treesitter
Syntax + code structure
  • Accurate syntax highlighting for every language
  • Powers smart text objects and folding
which-key.nvim
Keybinding discovery
  • Press Space and wait — shows all available bindings
  • No need to memorise everything at once

Tmux — Key Bindings

Prefix is Ctrl+A

ShortcutWhat it does
Ctrl+A then cNew window
Ctrl+A then % / "Split pane vertically / horizontally
Ctrl+h/j/k/lMove between tmux panes AND Neovim splits seamlessly
Ctrl+A then dDetach session (keeps everything running)
Ctrl+F or tatmux-sessionizer — fzf project dirs, create/switch sessions
Ctrl+A then IInstall TPM plugins

Sessions persist across reboots via resurrect + continuum plugins.
